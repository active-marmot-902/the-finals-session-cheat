# The Finals Session Toolkit — feature reference

The The Finals session toolkit workflow separates loadout notes from arena references and session records. Named sections make the available options easier to find.

| Section | Description |
|---|---|
| Loadout notes | Equipment categories and the associated selection or configuration options. |
| Arena references | A dedicated section for arena references and the configuration details associated with that area. |
| Session records | Session and activity information grouped by the task or context it belongs to. |

The project page follows the same section structure.
